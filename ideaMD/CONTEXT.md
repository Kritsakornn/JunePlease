# ขยับกับหลาน

แอปออกกำลังกายสำหรับผู้สูงอายุ ที่ใช้ใบหน้าและเสียงของหลานให้การขยับร่างกายรู้สึกเหมือนหลานแวะมาชวน ไม่ใช่การถูกบังคับโดยแอปสุขภาพ

## Language

**ผู้สูงอายุ**:
คนที่ออกกำลังกายตามเซสชัน และเป็นคนที่แอปพูดด้วยบนหน้าจอหลัก
_Avoid_: user, ผู้ใช้ทั่วไป, คนไข้

**หลาน**:
สมาชิกครอบครัวที่ใบหน้าและเสียงถูกใช้เป็นเทรนเนอร์ และเป็นผู้ตั้งตารางเวลา ชุดท่า และเสียงเรียก ก่อนการเรียกจากหลาน
_Avoid_: เทรนเนอร์, โค้ช, ผู้ดูแล (คนละบทบาท)

**การตั้งค่าของหลาน**:
การที่หลานเลือกท่าที่จะอยู่ในชุดท่า และช่วงเวลาของเซสชัน ไว้ล่วงหน้าก่อนผู้สูงอายุถูกเรียก
_Avoid_: ตั้งค่าตอนเดโม, onboarding, admin

**เซสชัน**:
รอบออกกำลังกายหนึ่งครั้งที่ผู้สูงอายุทำตามหลานจนจบหรือจนหยุด
_Avoid_: คลาส, เวิร์กเอาต์, โปรแกรม

**ตารางเวลา**:
ช่วงเวลาที่กำหนดไว้ว่าเซสชันควรเริ่มเมื่อไหร่
_Avoid_: ปฏิทิน, ตาราง (กำกวม), schedule

**การ์ดตารางเวลา**:
ช่องเซสชันของวันนี้บนหน้าผู้สูงอายุ การกดช่องนี้เริ่มการเรียกจากหลาน
_Avoid_: ปุ่มจำลองถึงเวลา, alarm trigger

**ชุดท่า**:
รายการท่าเรียงลำดับภายในเซสชันหนึ่งครั้ง และวิธีทำแต่ละท่า
_Avoid_: ตาราง, โปรแกรม, เวิร์กเอาต์, routine

**คลังท่า**:
รายการท่าที่หลานหยิบไปใส่ชุดท่า ทั้งหมดทำขณะนั่งเก้าอี้ อ้างอิงท่าจากคลิปออกกำลังกายผู้สูงอายุแบบนั่ง แต่ไม่เล่นคลิปนั้นระหว่างเซสชัน
_Avoid_: คลิปเต็ม, วิดีโอเทรนเนอร์, ท่าที่ต้องยืน

**ท่าตัว T**:
กางแขนออกด้านข้างระดับไหล่ แล้วยกและวาง
_Avoid_: T-pose, jumping jack

**ท่าวาดไหล่**:
มือจับหัวไหล่แล้ววาดเป็นวงกลม
_Avoid_: arm circles แบบแขนเหยียดตรง

**ท่าชกสลับ**:
ชกไปด้านหน้าสลับซ้ายขวา
_Avoid_: ชกข้าง, boxing

**การเรียกจากหลาน**:
จังหวะที่แอปชวนผู้สูงอายุให้เริ่มเซสชัน ด้วยใบหน้าหลานบนจอและการกดเริ่มครั้งเดียว
_Avoid_: การแจ้งเตือน, notification, alarm, push

**เสียงเรียก**:
คลิปเสียงหลานที่อัดไว้ล่วงหน้าหนึ่งไฟล์ สำหรับการเรียกจากหลาน โดยมีข้อความใหญ่บนจอเป็นคำบรรยายสำรอง
_Avoid_: เสียงสังเคราะห์ตอนนั้น, TTS, เสียงติ๊ด

**การดูผู้สูงอายุ**:
การที่แอปมองผู้สูงอายุผ่านกล้องระหว่างเซสชัน ขณะที่ผู้สูงอายุมองหลานบนจอ
_Avoid_: motion detect, tracking, computer vision

**การตรวจท่าทาง**:
การดูว่าร่างกายผู้สูงอายุตรงกับท่าปัจจุบันในชุดท่าหรือยัง
_Avoid_: pose estimation, skeleton, joint tracking

**การตรวจใบหน้า**:
การดูว่าใบหน้าผู้สูงอายุอยู่ในเฟรมและหันเข้าจอ ไม่ใช่การพิสูจน์ว่าเป็นคนนี้
_Avoid_: ยืนยันตัวตน, face recognition, ตรวจจับคุณยาย (กำกวม)

**การผ่านท่า**:
ท่าปัจจุบันจบเมื่อผู้สูงอายุถือท่าได้ใกล้เคียง, เมื่อหมดเวลาของท่านั้น, หรือเมื่อข้ามท่า
_Avoid_: สำเร็จ, complete, win

**ฟีดแบ็กท่า**:
ข้อความใหญ่และสีบนจอ ที่บอกผู้สูงอายุว่าท่าปัจจุบันไปได้ดีหรือยังไม่ครบ
_Avoid_: เสียงแก้ท่า, coach cue, realtime voice correction

**ภาพระหว่างเซสชัน**:
ผู้สูงอายุเห็นภาพกล้องของตัวเองคู่กับฟีดแบ็กท่า และมีจุดเล็กที่มือหรือไหล่ตอนท่าใกล้ครบ ไม่โชว์โครงข้อต่อเต็มตัว
_Avoid_: skeleton, โครงเต็มตัว, pose overlay

**หน้าชม**:
หน้าสั้นหลังเซสชันจบ ที่ชมผู้สูงอายุแล้วกลับไปตารางเวลา
_Avoid_: สถิติ, กราฟ, dashboard

**สรุปเซสชัน**:
ข้อความบันทึกว่าเซสชันจบแล้ว ชุดท่าไหน และผ่านกี่ท่า สำหรับหน้าหลาน กล้องไม่ถูกส่งออกไปด้วย
_Avoid_: รายงานสุขภาพ, medical record, analytics, คลิปกล้อง, รูปจากกล้อง

**หน้าหลาน**:
มุมมองของหลานในแอป สำหรับการตั้งค่าของหลาน และการดูสรุปเซสชัน ไม่ใช่หน้าหลักของผู้สูงอายุ
_Avoid_: admin, dashboard, caregiver app, LINE

**บทบาทบนจอ**:
แอปเครื่องเดียวสลับได้ระหว่างหน้าผู้สูงอายุกับหน้าหลาน ค่าเริ่มต้นเป็นผู้สูงอายุ
_Avoid_: สองแอป, สองลิงก์, admin mode
