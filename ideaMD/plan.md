จนกว่าจะเปิดบนทีวี ห้ามเดาธีม ห้ามเริ่มทำของตามธีมที่คิดเอง ห้ามเขียนโจทย์ให้

ตอบและเขียนคำอธิบายเป็นภาษาไทย ชื่อไฟล์ คำสั่ง และโค้ดเป็นภาษาอังกฤษตามปกติ

## ก่อนเริ่ม

- ติดตั้ง Cursor แล้ว และล็อกอินแล้ว
- หนึ่งรีโป GitHub ชวนทั้งทีม
- ทุกคน clone แล้วเปิดโฟลเดอร์นั้นใน Cursor
- แชร์ด้วย git ไม่ใช้ Drive ไม่ส่งใน LINE

### รีโป

1. คนหนึ่งสร้างรีโปว่างบน GitHub (`gh repo create` หรือ New repository)
2. เพิ่มทุกคนเป็น collaborator
3. ทุกคน `git clone` แล้ว File → Open Folder ใน Cursor รีโมตเดียวกัน
4. ก่อนลงมือดึงของใหม่ `git pull` แล้วค่อย commit / push

ห้าม zip โปรเจกต์ ห้ามวาง working tree บน Drive, Dropbox หรือ LINE

มาคนเดียว ไม่ต้องเชิญใคร

## ติดเพิ่มได้ ฟรีทั้งหมด

ติดก่อนมา ไวไฟร้านจะช้า

- Node.js LTS
- Chrome
- บัญชี Vercel — ลิงก์เดโมฟรี (ใช้ `vercel` CLI ได้)
- GitHub Desktop เฉพาะคนในทีมที่ไม่ต้องการ CLI

ต้องมี Cursor ถ้าไม่ใช่คนเดียว ต้องมีบัญชี GitHub

วันงาน ใช้ฟรีได้เช่นกัน: ElevenLabs, Wispr Flow
